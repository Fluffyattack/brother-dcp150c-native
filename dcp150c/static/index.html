    Maintenance at the printer

    These instructions open the model's official manual. Device actions are performed at the printer; this panel sends no maintenance commands.

    Check print quality

    At the printer: Ink Management → Test Print → Print Quality. Confirm the choices with OK, then press Colour Start for the check sheet.

    Open Brother's manual

    Check alignment

    Use Ink Management → Test Print → Alignment and follow the check sheet and display.

    Open Brother's manual

    Clean the scanner glass

    Use a soft, lint-free cloth dampened with non-flammable glass cleaner for the glass and white cover.

    Open Brother's manual

    Print head care

    Cleaning consumes ink. Follow the manual when needed; never touch the print head.

    Open Brother's manual

    Back up and restore

    Download a ZIP file containing the documents you select in Documents, their original dates and recognised text. You can include profiles and settings. Keep this file somewhere private.

    Restored files are added as new documents. Existing documents remain available. Temporary files receive a new retention period; files marked Keep stay retained.

    Prepared downloads are available for one hour. Removing a prepared backup leaves its original documents available. Passwords, job history and active scanning documents are excluded.

    Document storage

    Documents marked Keep are excluded from automatic expiry. New uploads must still fit within the storage limit.
